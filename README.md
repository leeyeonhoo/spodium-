# Spodium On for Android

안드로이드 7.0 이상에서 실행할 수 있는 Spodium On 앱입니다.

## 바로 설치

[SpodiumOn.apk 다운로드](https://github.com/leeyeonhoo/spodium-/releases/latest/download/SpodiumOn.apk)

휴대폰 카메라로 저장소에 포함된 설치 QR을 스캔하거나 위 링크를 열어 APK를 내려받으세요. Android가 설치를 막으면 다운로드에 사용한 브라우저 또는 파일 앱에 대해 **출처를 알 수 없는 앱 설치 허용**을 켜면 됩니다.

## 주요 기능

- 기존 Spodium On 디자인과 시연 기능 유지
- '어디로 갈까요?' 지도의 전체 경로를 이동 중 계속 표시
- 이동 시뮬레이션에서 현재 위치를 경로를 따라 지속적으로 갱신
- 층간 이동 경로 지원
- 앱 콘텐츠를 Android WebView에서 로컬 실행
